# Diseases — ветка `vetka-fix` (1.2.1)

Экспериментальная и исправленная версия мода **Diseases** для Minecraft **1.21.11** (Fabric).  
Независимый проект, вдохновлённый идеей ютубера **leafxup** (написан полностью с нуля).

Каждые **6–8 минут** каждый игрок получает случайную болезнь из **32 доступных**. Болезни суммируются, **сохраняются после смерти**, лечатся по одной **зачарованным золотым яблоком** и сбрасываются каждые **5 игровых дней**.

---

## Что нового в `vetka-fix` (1.2.1)

- **Настоящий звук икоты:** добавлены два пользовательских `.ogg` звука икоты и субтитры (`Икота` / `Hiccup`) вместо старого звука отрыжки.
- **Взаимоисключение Карликовости и Гигантизма:** пока активна одна из этих болезней, вторая не выпадает (после 5-дневного сброса снова может выпасть любая). Таймер корректно переходит в «Все болезни получены» на 31 болезни.
- **Умная пауза в интерфейсах:** болезни не мешают в инвентаре, сундуках, бочках, шалкерах, верстаках и меню паузы, но продолжают работать в открытом чате.
- **Глухота без порчи настроек:** громкость снижается до 8% на уровне звукового движка, не трогая `options.txt` — при вылете игры звук не собьётся.
- **Хромота через атрибут скорости:** замедляет только ходьбу и бег, не ломая прыжки и физику воды.
- **Клаустрофобия:** срабатывает только от твёрдых блоков с коллизией (факелы, трава и таблички больше не вызывают панику).
- **Остеопороз:** даже смертельное падение всегда выдаёт кастомное сообщение о смерти, а зачарование «Невесомость» корректно снижает урон.
- **Улучшенные команды для оператора / хоста:**
  - `/disease random [игрок]` — выдать случайную болезнь.
  - `/disease give <название | all> [игрок]`, `/disease take <название> [игрок]`, `/disease clear [игрок]` — если ник не указан, действует на себя; если указан ник в конце — на этого игрока.
  - `/disease list` и `/disease info <название>` доступны всем игрокам.

## Установка

1. Установите **Minecraft 1.21.11**, **Fabric Loader** (`>= 0.20.1`) и **Fabric API**.
2. Скачайте **`diseaseVetkaFix-1.2.1.jar`** из раздела **Releases** и положите в папку `mods/` **на клиенте и на сервере** (у всех игроков).

## Сборка из исходников

Требуется JDK 25 для запуска Gradle (целевой байткод Java 21):

```bash
./gradlew build
```

Готовый файл появится в `build/libs/diseaseVetkaFix-1.2.1.jar`.
