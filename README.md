Независимый мод для **Minecraft 1.21.11 (Fabric)**, написанный с нуля.  
Вдохновлён концепцией с канала ютубера **leafxup** (все игровые механики, сетевая синхронизация, звуковой движок и шейдерные эффекты разработаны полностью самостоятельно).

Каждые **6–8 минут** в один общий момент времени каждый игрок на сервере или в одиночной игре получает случайную «жизненную» болезнь из **38 доступных**. Болезни накапливаются, **не пропадают после смерти**, лечатся по одной **зачарованным золотым яблоком** и полностью сбрасываются раз в **5 игровых дней**.

---

## Основные особенности версии 1.3.0 Rebalance

- **38 разнообразных болезней:** от физических недугов (слепота, астма, переломы) до фобий (аквафобия, гелиофобия, клаустрофобия), психологических состояний (шизофрения, паранойя, ОКР) и мемных механик («Неуважение к пчёлам»).
- **Матрица взаимоисключений (`isCompatible`):** несовместимые болезни (например, карликовость и гигантизм, алексия и дислексия, анемия и порок сердца) не могут выпасть одному игроку одновременно.
- **Умная пауза:** дебаффы не мешают при работе в инвентаре, сундуках, верстаках и меню паузы.
- **Свои звуки и визуал:** кастомные звуки икоты (`hiccup.ogg`), процедурный стук сердца (`heartbeat.ogg`) при панических атаках, пульсирующая виньетка и покачивание камеры.
- **Информативный HUD:** список активных болезней в левом верхнем углу и таймеры до следующей болезни / 5-дневного сброса в правом верхнем углу экрана.
- **Кастомные сообщения о смерти:** отдельные причины гибели от панических атак, остеопороза, аллергии и невыполненных заданий ОКР.

## Матрица несовместимостей

Некоторые болезни исключают друг друга и не могут быть получены одновременно:
1. **Карликовость ⚡ Гигантизм**
2. **Алексия ⚡ Дислексия**
3. **Немота ⚡ Заикание**
4. **Слепота ⚡ Туннельное зрение**
5. **Слепота ⚡ Куриная слепота**
6. **Анемия ⚡ Порок сердца**

При попытке выдать конфликтующую болезнь оператором через `/disease give` команда выведет понятную причину отмены.

## Команды

Все команды работают с автодополнением по клавише `Tab`:

- `/disease list` — список всех болезней и статус их наличия у себя *(доступно всем игрокам)*.
- `/disease info <название>` — подробная справка по механике болезни *(доступно всем игрокам)*.
- `/disease give <название | all> [игрок]` — выдать болезнь себе или указанному игроку *(оператор / хост)*.
- `/disease take <название> [игрок]` — снять болезнь *(оператор / хост)*.
- `/disease clear [игрок]` — снять все болезни *(оператор / хост)*.
- `/disease random [игрок]` — выдать одну случайную совместимую болезнь *(оператор / хост)*.

## Требования и установка

### Системные требования:
- **Minecraft**: `1.21.11`
- **Fabric Loader**: `>= 0.20.1`
- **Fabric API**: `>= 0.141.6+1.21.11`
- **Java**: 21+

### Установка:
1. Скачайте файл **`diseaseRebalance-1.3.0.jar`** со страницы [Releases](https://github.com/qpwqp069-sys/disease/releases/tag/v1.3.0-rebalance).
2. Поместите файл в папку `.minecraft/mods/` **на клиенте и на сервере** (при игре по сети или LAN мод должен быть установлен у всех участников).

---

## Сборка из исходников

Для сборки требуется JDK 25:

```bash
# Windows (PowerShell)
$env:JAVA_HOME = "C:\Program Files\Java\jdk-25"
.\gradlew.bat clean build --no-daemon

# Linux / macOS
./gradlew clean build
```

Собранный файл появится по пути: `build/libs/diseaseRebalance-1.3.0.jar`.
