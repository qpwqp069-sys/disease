# Diseases — ветка `vetka-fix` (1.2.2)

Экспериментальная и доработанная версия мода **Diseases** для Minecraft **1.21.11** (Fabric).  
Независимый проект, вдохновлённый идеей ютубера **leafxup** (написан полностью с нуля).

Каждые **6–8 минут** каждый игрок получает случайную болезнь из **34 доступных**. Болезни суммируются, **сохраняются после смерти**, лечатся по одной **зачарованным золотым яблоком** и сбрасываются каждые **5 игровых дней**.

---

## Что нового в `1.2.2`

- **Новая болезнь — Гелиофобия (`heliophobia`):** днём в ясную погоду под открытым небом темнеет в глазах, а через 8 секунд начинается паническая атака с уроном и сердцебиением. Под крышей, в дождь/грозу, в воде, ночью, а также в Незере и Энде — безопасно. Добавлен тип урона `diseases:panic_sun` и сообщения о смерти.
- **Новая болезнь — Слабые руки (`weak_hands`):** при ударе моба, получении урона или затяжном беге предмет из главной руки может выскользнуть прямо перед игроком (откат 15–20 секунд, звук выпадения, облачные частицы и надпись над хотбаром).
- **Живое сердцебиение и пульсация при панике:** во время панической атаки (`exposure >= 8` сек) каждые 0.5 сек звучит очищенный живой стук сердца (`heartbeat1.ogg` / `heartbeat2.ogg` + субтитры), в такт бьётся бордово-красная виньетка по краям экрана и слегка подрагивает камера.

## Изменения из `1.2.1`

- **Настоящий звук икоты:** добавлены два пользовательских `.ogg` звука икоты и субтитры (`Икота` / `Hiccup`) вместо старого звука отрыжки.
- **Взаимоисключение Карликовости и Гигантизма:** пока активна одна из этих болезней, вторая не выпадает (после 5-дневного сброса снова может выпасть любая). Таймер корректно переходит в «Все болезни получены» при получении всех совместимых болезней.
- **Умная пауза в интерфейсах:** болезни не мешают в инвентаре, сундуках, бочках, шалкерах, верстаках и меню паузы, но продолжают работать в открытом чате.
- **Глухота без порчи настроек:** громкость снижается до 8% на уровне звукового движка, не трогая `options.txt` — при вылете игры звук не собьётся.
- **Хромота через атрибут скорости:** замедляет только ходьбу и бег, не ломая прыжки и физику воды.
- **Клаустрофобия:** срабатывает только от твёрдых блоков с коллизией (факелы, трава и таблички больше не вызывают панику).
- **Остеопороз:** даже смертельное падение всегда выдаёт кастомное сообщение о смерти, а зачарование «Невесомость» корректно снижает урон.
- **Улучшенные команды для оператора / хоста:**
  - `/disease random [игрок]` — выдать случайную болезнь.
  - `/disease give <название | all> [игрок]`, `/disease take <название> [игрок]`, `/disease clear [игрок]` — если ник не указан, действует на себя; если указан ник в конце — на этого игрока.
  - `/disease list` и `/disease info <название>` доступны всем игрокам.

## Установка

1. Установите **Minecraft 1.21.11**, **Fabric Loader** (`>= 0.20.1`) и **Fabric API**.
2. Скачайте **`diseaseVetkaFix-1.2.2.jar`** из раздела **Releases** и положите в папку `mods/` **на клиенте и на сервере** (у всех игроков).

## Сборка из исходников

Требуется JDK 25 для запуска Gradle (целевой байткод Java 21):

```bash
./gradlew build
```

Готовый файл появится в `build/libs/diseaseVetkaFix-1.2.2.jar`.
