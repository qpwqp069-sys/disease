# Diseases Rebalance — ветка `vetka-fix` (1.3.0)

[![Minecraft](https://img.shields.io/badge/Minecraft-1.21.11-brightgreen.svg)](https://minecraft.net/)
[![Fabric](https://img.shields.io/badge/Fabric-0.20.1+-blue.svg)](https://fabricmc.net/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Независимый мод для **Minecraft 1.21.11 (Fabric)**, написанный с нуля.  
Вдохновлён концепцией с канала ютубера **leafxup** (все механики, сетевой код и шейдерные эффекты разработаны полностью самостоятельно).

Каждые **6–8 минут** в один общий момент времени каждый игрок получает случайную «жизненную» болезнь из **38 доступных**. Болезни накапливаются, **не пропадают после смерти**, лечатся по одной **зачарованным золотым яблоком** и полностью сбрасываются раз в **5 игровых дней**.

---

## Что нового в версии 1.3.0 Rebalance

1. **4 новые болезни (всего 38):**
   - **Неуважение к пчёлам (`bee_disrespect`)**: «Кто пчёлок уважает — кто к ним не пристает...» Любая живая пчела в радиусе 16 блоков при наличии прямой видимости автоматически становится агрессивной и летит жалить игрока без всякого удара с его стороны. Лимит: не более 4 новых пчёл в секунду. В приседе радиус обнаружения уменьшается вдвое.
   - **Короткие руки (`short_arms`)**: Дистанция взаимодействия с блоками снижена на 2 блока, дистанция удара сущностей — на 1.5 блока. Приходится подходить к объектам вплотную.
   - **Мышечная слабость (`muscle_weakness`)**: Скорость добычи блоков снижена на 50% (блоки ломаются вдвое дольше). При этом возможность бить мобов и базовый урон сохранены в полном объёме.
   - **Порок сердца (`heart_disease`)**: Максимальный запас здоровья снижен на 6 единиц — у игрока остаётся 7 сердец (14 HP).

2. **Матрица несовместимостей болезней (`isCompatible`):**
   - Карликовость ⚡ Гигантизм
   - Алексия ⚡ Дислексия
   - Немота ⚡ Заикание
   - Слепота ⚡ Туннельное зрение
   - Слепота ⚡ Куриная слепота
   - Анемия ⚡ Порок сердца  
   *Несовместимые пары не могут выпасть случайным образом одновременно, а при ручной выдаче через `/disease give` команда вежливо предупредит о конфликте.*

3. **Баланс и исправления из прошлых версий (1.2.1 и 1.2.2):**
   - **Гелиофобия (`heliophobia`)**: паническая атака на ярком дневном солнце под открытым небом.
   - **Слабые руки (`weak_hands`)**: шанс выронить предмет из рук при ударе, получении урона или спринте.
   - **Живое сердцебиение и виньетка**: процедурный стук сердца (`heartbeat1/2.ogg`) и пульсирующая виньетка экрана во время приступов паники.
   - **Звук икоты**: кастомные `.ogg` сэмплы икоты вместо ванильной отрыжки.
   - **Умная пауза**: дебаффы не мешают при работе в инвентаре, сундуках, верстаках и меню паузы.
   - **Хромота**: реализована через атрибут скорости ходьбы/бега, не ломая прыжки и плавание.
   - **Глухота**: приглушает звук через игровой аудиомикшер без изменения файла `options.txt`.

## Команды

- `/disease list` — просмотр списка всех болезней мода и статуса их наличия у себя *(доступно всем)*.
- `/disease info <название>` — подробная справка по механике болезни *(доступно всем)*.
- `/disease give <название | all> [игрок]` — выдать болезнь конкретному игроку или себе *(оператор / хост)*.
- `/disease take <название> [игрок]` — снять болезнь *(оператор / хост)*.
- `/disease clear [игрок]` — очистить все болезни *(оператор / хост)*.
- `/disease random [игрок]` — выдать одну случайную совместимую болезнь *(оператор / хост)*.

## Требования и установка

- **Minecraft**: `1.21.11`
- **Fabric Loader**: `>= 0.20.1`
- **Fabric API**: `>= 0.141.6+1.21.11`
- **Java**: 21+ (для компиляции из исходников требуется JDK 25)

### Установка:
1. Скачайте **`diseaseRebalance-1.3.0.jar`** из раздела **Releases**.
2. Поместите файл в папку `.minecraft/mods/` **как на клиенте, так и на сервере** (при игре по сети мод должен стоять у всех участников).

---

## Сборка из исходников

```bash
# Windows (PowerShell)
$env:JAVA_HOME = "C:\Program Files\Java\jdk-25"
.\gradlew.bat clean build --no-daemon

# Linux / macOS
./gradlew clean build
```

Собранный `.jar` появится в `build/libs/diseaseRebalance-1.3.0.jar`.
