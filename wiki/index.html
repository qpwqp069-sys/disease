Diseases Rebalance выдаёт всем игрокам одновременно случайную болезнь из 38. Они копятся, не проходят после смерти, лечатся по одной зачарованным золотым яблоком и отступают раз в пять игровых дней.

§1 Течение болезни

  1. 00:00

    Заражение

    Раз в 6–8 минут общий таймер срабатывает для всех на сервере сразу. Каждый получает случайную болезнь, совместимую с теми, что у него уже есть.

  2. + n × 7 мин

    Накопление

    Болезни складываются. Смерть их не снимает: после возрождения всё на месте, включая атрибуты вроде роста и запаса здоровья.

  3. лечение

    Зачарованное золотое яблоко

    Когда вы доедаете яблоко, проходит одна случайная болезнь. Других лекарств нет, поэтому сундуки с добычей становятся аптекой.

  4. 5 игровых дней

    Ремиссия

    Через 5 игровых дней (около 100 минут) болезни у всех игроков проходят разом. Таймер сброса виден в правом верхнем углу экрана.

  • Умная пауза. Клиентские эффекты (тряска, судороги, головокружение) не мешают, пока открыт инвентарь, сундук или меню паузы.
  • Креатив и наблюдатель защищены от эффектов болезней.
  • HUD. Слева вверху список ваших болезней, справа таймеры. Новая болезнь появляется баннером по центру.

§3 Противопоказания

Эти болезни не выпадают одному игроку одновременно. Команда /disease give тоже откажет и объяснит причину.

    §4 Установка

    1. Fabric Loader

      Установите Fabric Loader версии ≥ 0.20.1 для Minecraft 1.21.11.

    2. Fabric API

      Скачайте Fabric API ≥ 0.141.6 и положите его в .minecraft/mods/.

    3. Сам мод

      Скачайте jar и положите туда же.

    4. Сервер и все игроки

      Для игры по сети или LAN мод нужен и на сервере, и у каждого игрока: часть симптомов (заикание, алексия, глухота, судороги) работает на клиенте.

    Сборка из исходников 
    # Linux / macOS
git clone https://github.com/qpwqp069-sys/disease.git
cd disease
./gradlew clean build

# Windows (PowerShell)
.\gradlew.bat clean build --no-daemon

# Готовый файл:
build/libs/diseaseRebalance.jar

    §5 Команды

    Все команды поддерживают автодополнение по Tab. Болезнь можно указать по id (blindness) или по названию (Слепота).

    КомандаЧто делаетДоступ
    /disease listВсе болезни мода, отмечены те, что есть у васвсе
    /disease info <болезнь>Подробная механика болезнивсе
    /disease give <болезнь | all> [игрок]Выдать болезнь или все совместимые сразуоператор
    /disease take <болезнь> [игрок]Снять одну болезньоператор
    /disease clear [игрок]Снять все болезниоператор
    /disease random [игрок]Выдать одну случайную совместимую болезньоператор
